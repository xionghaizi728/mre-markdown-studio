## What this repository is

It is **not a monorepo** — there is no workspace/multi-package layout, just one `package.json` with `src/` modules. It was scaffolded from the `vuejs-templates/webpack` template (v1.3.1) and is a downloaded snapshot (no `.git`, `node_modules/` empty). Source is small: ~5.8k lines of `.vue`/`.js`, of which 2.8k is vendored Bootstrap JS.

Stack: **Vue 2.6 + vue-router 3 + vuex 3 + Element UI 2.15 + axios 0.21**, built by **webpack 3 + Babel 6 + node-sass 4**, dev-proxied to a Java backend on `localhost:8021`.

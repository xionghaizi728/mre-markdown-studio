# 欢迎使用 MRE 写作台

这是一个跑在本机的 Markdown 读写工作台：左边选文件，中间写，右边实时预览，`Ctrl + S` 保存。

## 你能做的事

- 浏览 `docs/` 目录下的所有 `.md` / `.markdown` 文件
- 新建、重命名、删除文档（支持子目录，例如 `笔记/周报.md`）
- 编辑时实时预览，支持 GFM 表格、任务列表、代码块
- 手动保存，或打开「自动保存」让改动自动落盘

## 常用快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl + S` | 保存当前文档 |
| `Ctrl + B` | 加粗 |
| `Ctrl + I` | 斜体 |
| `Ctrl + N` | 新建文档 |
| `Tab` | 在编辑区插入两个空格 |

## Markdown 语法示例

### 列表

1. 有序列表
2. 支持嵌套
   - 无序子项
   - 再来一条

- [x] 已完成的任务
- [ ] 待办的任务

### 代码块

```js
// 代码块会保留缩进并使用等宽字体
function greet(name) {
  return `你好，${name}！`;
}
```
